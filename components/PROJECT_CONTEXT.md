# LegionHunt OS — Project Context

## О проекте

LegionHunt OS — корпоративная операционная система для управления компанией LegionHunt.

Это НЕ CRM.

Это единая рабочая среда компании.

---

# Основной стек

- Next.js 16 (App Router)
- React
- TypeScript
- TailwindCSS
- Supabase
- PostgreSQL
- Vercel

---

# Основные принципы

Никогда не ломать существующий функционал.

Перед изменением существующего компонента сначала анализировать его полностью.

Предлагать минимальные изменения.

Всегда учитывать архитектуру проекта.

# Авторизация

Используется Supabase Auth.

Регистрация реализована.

Профиль пользователя создается автоматически триггером.

Используется таблица:

profiles

---

# Роли

owner

admin

mentor

manager

user

Все права строятся через поле

profiles.role

---

# Owner

Owner имеет полный доступ.

Только owner может

- менять роли
- блокировать пользователей
- видеть административные панели

---

# Пользователи

Есть отдельная панель

/team/users

В ней реализовано:

- список пользователей
- смена ролей
- блокировка
- поиск
