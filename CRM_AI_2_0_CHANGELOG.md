# CRM 2.0 + AI Intelligence

- AI получает актуальную сводку LegionHunt из PostgreSQL.
- Контекстный поиск по CRM, Wiki, Team и Academy.
- Внутренние факты ограничены найденным контекстом: при отсутствии данных AI обязан сообщить об этом.
- Ответ API возвращает список использованных внутренних источников.
- В AI Center показываются кликабельные карточки источников.
- API-ключ Gemini остаётся только на сервере.
